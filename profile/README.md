### Tentang

Laboratorium ini dirancang untuk menjembatani teori kurikulum dengan standar industri perangkat lunak modern. Kami berfokus pada pengembangan aplikasi web, mobile, manajemen basis data, serta penerapan *clean code*.

* **Hands-on Coding:** Siswa belajar membangun aplikasi nyata berbasis proyek (*Project-Based Learning*).
* **Industry Workflow:** Pembiasaan menggunakan Git, GitHub, dan *code review*.
* **Modern Tech Stack:** Adopsi framework modern (Laravel, Flutter) dan integrasi Generative AI terarah.
